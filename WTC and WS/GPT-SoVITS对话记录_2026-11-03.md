## 1. GPT-SoVITS 基本使用方法

### 使用步骤

**1. 准备训练数据**

- 收集目标说话人的音频（通常3-10分钟）
- 音频需要清晰、无背景噪音
- 准备对应的文字标注（transcript）

**2. 训练/微调模型**

- 使用提供的训练脚本进行微调
- 通常需要GPU加速
- 训练时间取决于数据量和硬件

**3. 推理（生成语音）**

- 输入文字 + 参考音频
- 模型会生成目标说话人声音的语音
- 支持中英文等多语言

### 常见使用场景

- 语音助手定制
- 有声书制作
- 游戏/动画配音
- 个人语音备份

### 注意事项

- 需要NVIDIA GPU（推荐6GB+显存）
- 训练数据质量直接影响效果
- 推理时参考音频的质量也很重要

## 2. 模型文件说明

### 用户提供的文件

- `linpianpian_01_e4_s556.pth` (172MB) - GPT模型权重（epoch 4, step 556）
- `linpianpian-e15.ckpt` (155MB) - SoVITS模型权重（epoch 15）
- `linpianpian-rvc.pth` (57MB) - RVC模型权重

### 文件存放位置

```
GPT-SoVITS/
├── weights/
│   ├── linpianpian_01_e4_s556.pth    ← GPT模型
│   └── linpianpian-e15.ckpt          ← SoVITS模型
```

RVC 模型放到 `RVC/weights/` 或项目指定的 RVC 目录。

### 推理操作

启动 WebUI：

```bash
python webui.py
```

在界面中：

- 选择 GPT 模型：`linpianpian_01_e4_s556.pth`
- 选择 SoVITS 模型：`linpianpian-e15.ckpt`
- 输入要合成的文字
- 上传参考音频（训练时用的原声）
- 点击生成

## 3. 视频生成 + 语音合成工作流

### 方案一：分开制作，后期合成（简单）

```
1. 准备台词文本
   ↓
2. 用 GPT-SoVITS 生成语音（linpianpian 模型）
   ↓
3. 用视频生成工具制作画面（人物动作）
   ↓
4. 用剪辑软件合成：视频 + 音频对齐
```

### 方案二：口型同步（复杂但效果真实）

```
1. 准备台词 + 参考音频
   ↓
2. GPT-SoVITS 生成语音
   ↓
3. 用语音驱动口型工具（如 SadTalker、Wav2Lip、MuseTalk）
   - 输入：静态图片/视频 + 生成的音频
   - 输出：口型同步的视频
   ↓
4. （可选）用视频生成工具补充身体动作
```

### 推荐工具组合

| 步骤   | 工具                             |
| ---- | ------------------------------ |
| 语音合成 | **GPT-SoVITS**（linpianpian 模型） |
| 口型驱动 | **SadTalker** 或 **MuseTalk**   |
| 视频生成 | **Kling**、**可灵**、**Runway** 等  |
| 后期剪辑 | **剪映**、**PR**                  |

### 最简单的起步方式

1. 先用 GPT-SoVITS 生成一段语音
2. 用 SadTalker 让一张图片"说话"（输入图片+音频→输出视频）
3. 效果满意后再考虑加身体动作

## 4. 硬件配置分析

### 用户设备配置

- **CPU**: Intel i5-12450H（笔记本处理器）
- **GPU**: Intel UHD Graphics（核显，无独显）
- **没有 NVIDIA 显卡**

### 结论：本地跑不了，必须用云端

GPT-SoVITS、SadTalker、MuseTalk 这些工具都**强依赖 NVIDIA GPU（CUDA）**，核显无法运行。

### 云端方案推荐

| 工具             | 云端平台             | 说明              |
| -------------- | ---------------- | --------------- |
| **GPT-SoVITS** | AutoDL、恒源云、趋动云   | 租 GPU 服务器，按小时计费 |
| **SadTalker**  | 同上，或 Colab       | 有免费 Colab 笔记本可用 |
| **口型/视频生成**    | 可灵、Runway、HeyGen | 在线服务，直接上传使用     |

### 最省事的方案

1. **语音合成**：用云端 GPT-SoVITS（租 AutoDL，约 1-2 元/小时）
2. **口型驱动**：用 SadTalker Colab 免费版，或 HeyGen/可灵在线服务
3. **视频生成**：可灵、Runway 等在线平台

### 免费方案

- 使用 **Google Colab**（免费 T4 GPU）
- 可编写 Colab 笔记本，上传就能用
